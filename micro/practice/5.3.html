5.3

Least-Cost & Profit-Max Inputs

Read the theory → Drill 5.3 →

A. Marginal Product per Dollar

Problem 1. Labor has MP = 20 and costs $10; capital has MP = 30 and costs $20. Compute each input's marginal product per dollar. Which input should the firm use more of?

Show solution

Labor: 20/10 = 2 units per dollar.
Capital: 30/20 = 1.5 units per dollar.
Labor gives more output per dollar, so the firm should use more labor (and less capital) until the two ratios equalize.

Problem 2. A firm finds MPL/PL = 4 and MPK/PK = 4. Is it minimizing cost? Explain.

Show solution

Yes. The marginal product per dollar is equal across inputs (4 = 4), which is exactly the least-cost rule: no reallocation would produce the same output more cheaply.

Problem 3. Labor has MP = 40 at a wage of $8; capital has MP = 24 at a rental rate of $6. Which input should the firm expand?

Show solution

Labor: 40/8 = 5.
Capital: 24/6 = 4.
Labor's bang-per-buck is higher, so use more labor.

B. The Profit-Maximizing Condition

Problem 4. State the condition for the profit-maximizing combination of labor and capital.

Show solution

MRPL / PL = MRPK / PK = 1: equivalently, hire each input until its MRP equals its price.

Problem 5. A firm finds MRPL = $50 with a wage of $10. Is it using too little or too much labor, and what should it do?

Show solution

MRPL / PL = 50/10 = 5, which exceeds 1
→ each dollar of labor adds far more revenue than it costs.
The firm is using too little labor and should hire more (lowering MRPL toward the wage).

Problem 6. What extra information does the profit-maximizing rule capture that the least-cost rule does not?

Show solution

The least-cost rule (MPL/PL = MPK/PK) only fixes the cheapest input mix for a given output.
The profit-max rule adds "= 1" (MRP = price for each input), which also pins down the profit-maximizing quantity of each input, not just their ratio.

C. Checking Both Conditions at Once

Problem 7. A firm finds MRPL = $60 with a wage of $12, and MRPK = $90 with a rental rate of $18. (a) Is the firm using the least-cost mix? (b) Is it maximizing profit? (c) What should it do?

Show solution

(a) MRPL/PL = 60/12 = 5 and MRPK/PK = 90/18 = 5.
The ratios are equal, so the firm is at the least-cost mix.
(b) But 5 ≠ 1, so it is not maximizing profit.
(c) Each ratio exceeds 1 → every input adds more revenue than it costs → the firm should use more of both inputs (scale up), keeping the mix fixed, until both ratios fall to 1.

Problem 8. A firm finds MRPL = $40 with a wage of $10, and MRPK = $30 with a rental rate of $15. (a) Is it using the least-cost mix? (b) What adjustment lowers its cost for the current output?

Show solution

(a) MRPL/PL = 40/10 = 4 and MRPK/PK = 30/15 = 2.
The ratios are not equal (4 ≠ 2), so it is not least-cost.
(b) Labor gives more bang per dollar, so shift toward more labor and less capital — raising capital's MP and lowering labor's — until the two ratios equalize.

Problem 9. A firm finds MRPL/PL = 1 and MRPK/PK = 1. Is it (a) using the least-cost mix and (b) maximizing profit?

Show solution

(a) Yes — the ratios are equal (1 = 1), the least-cost condition.
(b) Yes — both ratios equal 1, so MRP = price for each input: the profit-maximizing condition.
The firm is at the optimum on both counts.
