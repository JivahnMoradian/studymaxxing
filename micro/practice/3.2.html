A. Total and Marginal Cost

Problem 1. Compute total cost (TC) at Q = 0 through 6.

Show solution

TC = FC + VC: 48, 68, 82, 94, 110, 136, 176.

Problem 2. Compute marginal cost for Q = 1 through 6.

Show solution

MC = ΔTC: 20, 14, 12, 16, 26, 40.

B. Average Costs

Problem 3. At Q = 4, compute AFC, AVC, and ATC.

Show solution

AFC = 48/4 = 12.
AVC = 62/4 = 15.5.
ATC = 110/4 = 27.5 (= AFC + AVC = 12 + 15.5 ✓).

Problem 4. At what output is ATC minimized? (Compute ATC across the table.)

Show solution

ATC = TC/Q: Q1 = 68, Q2 = 41, Q3 = 31.33, Q4 = 27.5, Q5 = 27.2, Q6 = 29.33.
Minimum ATC is at Q = 5.

Problem 5. At what output is AVC minimized?

Show solution

AVC = VC/Q: Q1 = 20, Q2 = 17, Q3 = 15.33, Q4 = 15.5, Q5 = 17.6, Q6 = 21.33.
Minimum AVC is at Q = 3.

C. Cost-Curve Relationships

Problem 6. Why does the vertical gap between the ATC and AVC curves shrink as output rises?

Show solution

Because ATC − AVC = AFC, and AFC = FC/Q falls continuously as output rises (the fixed cost is spread over more units).
So the gap narrows toward zero but never disappears.

Problem 7. Marginal cost at Q = 5 is 26 and at Q = 6 is 40, while minimum ATC (27.2) occurs at Q = 5. Explain what this illustrates about MC and ATC.

Show solution

MC (26) is below ATC just as ATC bottoms out, then MC (40) jumps above ATC, so MC crosses ATC right around its minimum. When MC < ATC it pulls ATC down; when MC > ATC it pulls ATC up.

Problem 8. Distinguish economies of scale from diseconomies of scale.

Show solution

Economies of scale: long-run average cost falls as output rises (spreading fixed costs, specialization). Diseconomies of scale: long-run average cost rises as output grows too large (coordination and management problems).
