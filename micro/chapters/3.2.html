UNIT 3 — PRODUCTION, COST & PERFECT COMPETITION

Costs of Production

Practice these problems →

Fixed, Variable, and Total Cost

  • Fixed Cost (FC): doesn't change with output (rent, insurance). Exists even at Q = 0.
  • Variable Cost (VC): rises with output (labor, materials).

Total Cost adds the two:

TC = FC + VC

The per-Unit (Average) and Marginal Costs

AFC = FCQ
AVC = VCQ
ATC = TCQ = AFC + AVC
MC = Δ TCΔ Q

Marginal Cost (MC) is the added cost of one more unit: the single most important cost concept for the firm's decisions.

The Shapes and How the Curves Relate

  • AFC falls continuously (a fixed cost spread over more units): the reason the gap between ATC and AVC narrows as Q rises (that gap is AFC).
  • MC, AVC, and ATC are U-shaped. MC falls then rises (because of diminishing marginal returns in 3.1).
  • MC passes through the minimum of both AVC and ATC. When MC is below an average curve it pulls it down; when MC is above it pulls it up, so they cross exactly at the average's lowest point (the same marginal-vs-average logic as MP and AP).

Short Run vs. Long Run

All the above are short-run curves (capital fixed). In the long run all inputs vary, giving a Long-Run Average Cost (LRAC) curve. Its shape reflects:

  • Economies of Scale: LRAC falls as output rises (spreading fixed costs, specialization).
  • Constant Returns to Scale: LRAC flat.
  • Diseconomies of Scale: LRAC rises (coordination problems at large size).
Go Deeper: College-Level

MC as a derivative, and why it cuts ATC at the minimum
Marginal cost is MC = dTC/dQ.
Average total cost, ATC = TC/Q, is minimized where its own derivative is zero.
Differentiate it with the quotient rule (treating TC as a function of Q, so dTC/dQ = MC):

d(ATC)dQ = ddQ(TCQ) = Q· MC - TCQ2

Setting the top equal to zero gives Q·MC − TC = 0, i.e.
MC = TC/Q = ATC.
So wherever ATC is flat (its minimum), marginal cost equals average total cost — which is exactly why the MC curve passes through the bottom of the ATC curve.
The intuition behind the algebra: when the next unit costs less than the running average (MC <
ATC), it drags the average down; when it costs more (MC >
ATC), it pulls the average up; the average stops falling and starts rising precisely where the two are equal.

Cost and Productivity are mirror images
Suppose labor is the only variable input and each worker is paid the wage w. One more worker costs you w and produces MP extra units, so the extra cost per unit of output is

MC = wMPand, the same way, AVC = wAP

Read that fraction carefully. When workers are very productive (MP is large), each extra unit is cheap, so MC is low. As diminishing returns set in and MP falls, each extra unit costs more, so MC rises. In other words, MC is just the MP curve flipped over: MP climbing to its peak corresponds to MC sliding down to its trough, and the point where MP is highest is exactly where MC is lowest. The same mirror relationship ties AVC to AP. So the cost curves of 3.2 are nothing new — they are the production curves of 3.1 turned upside down.
